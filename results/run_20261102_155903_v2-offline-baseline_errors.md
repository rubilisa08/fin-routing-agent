- [답변] 필수 사실 누락: 차변에는 자산의 증가, 부채의 감소, 자본의 감소, 비용의 발생을 기록한다
- [답변] 필수 사실 누락: 대변에는 자산의 감소, 부채의 증가, 자본의 증가, 수익의 발생을 기록한다

```
자산 계정: 증가는 차변, 감소는 대변. 잔액은 차변에 남는다. [AP-03]
부채 계정: 증가는 대변, 감소는 차변. 잔액은 대변에 남는다. [AP-03]
자본 계정: 증가는 대변, 감소는 차변. 잔액은 대변에 남는다. [AP-03]
차변과 대변은 '좋다·나쁘다'나 '들어옴·나감'이 아니라 기록 위치를 가리키는 말이다. [AP-03]
모든 회계상 거래는 차변과 대변에 같은 금액으로 기록된다(거래의 이중성). 그래서 전체 차변 합계와 대변 합계는 항상 같다(대차평균의 원리). [AP-02]
```

## Q03 배당은 어떻게 봐야 해?

```
배당성향 = 배당금 총액 ÷ 당기순이익 × 100 [VA-08]
배당수익률 = 주당배당금 ÷ 주가 × 100 [VA-08]
고든 성장 배당할인모형: P0 = D1 ÷ (r − g). D1은 내년 예상 주당배당금, r은 자기자본비용, g는 배당의 영구성장률이며 r > g여야 한다. [VA-08]
평가 결과를 볼 때는 어떤 가정을 썼는지, 가정을 바꾸면 결과가 얼마나 변하는지를 함께 봐야 한다. [VA-10]

```
