## H02 영업이익은 어떻게 계산해?
- 기대 도구 ['lookup_fs'] / 실제 ['handoff']
- [도구] 답할 수 있는데 넘김 — ① 판정 오류: 'other'(기대 'fs')로 분류되어 넘김
- [답변] 필수 사실 누락: 답할 수 있는데 넘김

```
[넘김] 학습노트 근거로는 답할 수 없어 답변을 보류합니다.
사유: 학습노트가 다루지 않는 범위 밖 질문입니다.
확인할 곳: 세무 상담은 세무사, 투자 판단은 본인 또는 투자자문업자, 실적 수치는 DART 원문
```

## H06 적정의견인데 계속기업 불확실성 문단이 붙어 있으면 무슨 뜻이야?
- 기대 도구 ['lookup_disclosure'] / 실제 ['lookup_fs']

## H08 LG에너지솔루션 PER 지금 몇 배야?
- 기대 도구 ['handoff'] / 실제 ['lookup_valuation']
- [도구] 넘겨야 하는데 ['lookup_valuation']로 답함 → 근거 밖 내용을 지어낼 위험
- [답변] 필수 사실 누락: 넘겨야 하는데 답을 지어냄

```
PER(주가수익비율) = 주가 ÷ 주당순이익(EPS) = 시가총액 ÷ 당기순이익 [VA-06]
PER에는 보편적으로 '적정한' 배수가 없다. [VA-06]
따라서 PER이 낮다는 사실만으로 저평가라고 판단할 수 없다. [VA-06]
이익이 일시적으로 부풀었거나 성장이 둔화될 것으로 시장이 예상하는 경우에도 PER이 낮게 나타난다. [VA-06]
당기순이익이 적자이면 PER은 의미가 없다. [VA-06]
```
