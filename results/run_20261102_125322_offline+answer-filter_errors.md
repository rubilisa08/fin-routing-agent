## E01 기타포괄손익은 당기순이익이랑 뭐가 달라? 나중에 전부 당기손익으로 옮겨지는 거야?
- 기대 도구 ['lookup_fs'] / 실제 ['lookup_fs']
- [답변] 필수 사실 누락: 재분류되지 않는 항목의 예(재평가잉여금, 확정급여제도 재측정요소, 기타포괄손익-공정가치 지분상품 평가손익 중 하나 이상)

```
기타포괄손익은 다른 기준서에서 당기손익으로 인식하지 않도록 요구하거나 허용하는 수익과 비용 항목이다. [FS-05]
기타포괄손익은 당기순이익에 포함되지 않고, 총포괄손익에 포함된다. [FS-05]
기타포괄손익은 후속적으로 당기손익으로 재분류되는지에 따라 두 집단으로 나누어 표시한다. [FS-05]
'재분류조정'은 당기나 과거 기간에 기타포괄손익으로 인식되었다가 당기손익으로 옮겨지는 금액이다. [FS-05]
즉, 모든 기타포괄손익이 나중에 당기손익으로 옮겨지는 것은 아니다. [FS-05]
```


```
연결재무제표는 지배기업과 그 종속기업의 자산, 부채, 자본, 수익, 비용, 현금흐름을 하나의 경제적 실체로 표시하는 재무제표이다. [FS-10]
별도재무제표는 지배기업이 작성하는 재무제표로서, 종속기업·관계기업·공동기업에 대한 투자를 원가법, K-IFRS 제1109호에 따른 공정가치법, 지분법 중 하나를 선택하여 회계처리한다. [FS-10]

K-IFRS 제1001호에 따른 전체 재무제표는 다음으로 구성된다. [FS-01]
재무제표는 계속기업을 전제로 작성한다. [FS-09]
```

## E06 유동비율이 150%면 위험한 거야?

- [근거] 필요한 섹션 ['RA-01']이 조립되지 않음 (조립: ['RA-04', 'FS-02', 'RA-05', 'RA-07'])

```

유동비율이 높다고 무조건 좋은 것도 아니다. [RA-04]
```
